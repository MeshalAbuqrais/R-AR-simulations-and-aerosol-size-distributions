# R-AR Simulations and Aerosol Size Distributions

This repository contains the code used for the numerical experiments and data application in the paper “Autoregressive Processes on Riemannian Manifolds.”

The repository includes simulations of Riemannian autoregressive processes in the hyperbolic plane, numerical studies of the estimators for the model parameters, and an application to aerosol size distributions.

## Contents

  This folder contains simulations of R-AR point trajectories in the Poincaré disk.

  This folder contains simulation studies for the parameters μ and φ, including generated outputs.

  This folder contains the aerosol size-distribution application, including data processing, lognormal parameter extraction, modelling, and visualisation outputs.
